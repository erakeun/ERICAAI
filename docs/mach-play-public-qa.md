## 적용 범위

- MACH NOW 바로 아래 기본 접힘 영역. 펼칠 때 `play/` 정적 자산을 불러오며, 접을 때 iframe을 제거해 게임 실행·입력을 종료합니다. 다시 펼치면 새 게임입니다.
- 기본속도·속도 초기화는 440px/s, 기존 조절 범위 220–440 유지. 달리기·할퀴기 이미지 24개와 애니메이션 모듈은 원본과 같습니다.
- 기존 공개 목록·사용 안내를 근거로 게임 내 18개 도구 설명 추가. MACH 30/31은 메인에 이미 있어 중복 등록하지 않고 게임 포털에만 추가했습니다.
- 비공개 건물은 일반 표식만 유지. 소유자 사이트 주소·실제 인증 연결·키패드는 제외했습니다. 원본 게임과 비공개 사이트의 소스·공유 설정은 변경하지 않았습니다.
- 명찰 PR30의 파일은 변경하지 않았습니다.

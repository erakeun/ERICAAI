# 명찰 로고 선택·디자인 확장 검증

검증일: 2026-10-26. 최초 소스 검증 기준은 `9b8f830c7e1d9fb95d4d180f3370ef7825641686`이다. 사용자 배포 승인 후 최신 main `fe1d663bbd9c6638432d47cd0267b18c67a3d50f`를 통합했고, PR #28의 메인·면접·역할맵 피드백 변경을 그대로 보존했다. 이 문서는 배포할 소스의 검증 기록이며, 실제 배포 결과는 별도 릴리스 증빙으로 확인한다.

## 변경

- 두 제작기에 로고 없음 / 한양대학교 / ERICA / 한양대학교+ERICA 선택을 추가했다. 새 작업은 두 로고를 기본으로 사용하며, 이전 v1 작업 파일은 원래의 한양대학교 로고로 복원한다.
- 기존 다섯 디자인에 블루 시그널, 네이비 프레임, 네이비 사이드를 추가해 여덟 디자인을 제공한다. 기존 메일 명함·안내문·디지털 사이니지·명패의 실제 자산과 구성을 바탕으로 했다.
- 원본 ERICA PNG 두 개를 바이트 변경 없이 복사하고, 각 로고의 원래 가로세로 비율과 투명성을 보존했다. 근거와 해시는 `badge-shared/design-provenance.md`에 있다.
- 미리보기·썸네일·인쇄·JSON 저장/복원이 같은 로고 선택을 사용한다. 로고와 문구의 경계·겹침 검사 및 한글 이름이 불필요하게 축소되지 않는 줄 간격을 적용했다.
- mm 설정, 일괄 명단, CSV 수식 보호, 사용자 텍스트의 비활성 처리, 브라우저 내 처리, 명시적 파일 저장 흐름을 유지했다. 기존 두 앱에는 사용자 로고 업로드 기능이 없었으므로 업로드 기능을 제거하거나 변경한 사항은 없다.

기본 조합의 삽입지 규격은 95×65, 85×54, 54×85, 95×122, 90×54, 75×40 mm이다. 각 조합에서 화면/인쇄 로고의 정상 로드·원본 비율 유지·카드 경계, 로고 간 및 로고/문구 간 겹침, 문구 잘림, 실제 mm 치수를 확인했다. 54×85 mm의 일반 이름은 의도한 글자 크기를 유지하는지도 별도 확인한다.

추가로 매우 긴 이름과 20×20 mm 사용자 규격의 모든 디자인·로고 조합에서 내용이 맞거나 명시적으로 인쇄가 차단되는지 확인했다. 17명 샘플은 90×54 mm에서 A4 3페이지로 출력된다. 선택 2명은 1페이지, 100 mm 시험 자는 1페이지로 확인했다.

검증은 기존 사용자 브라우저와 분리된 임시 Edge 프로필 및 자체 로컬 서버에서 실행했다. 샘플 명단은 전부 가상이다. 자동 로컬 저장과 외부 요청은 없었다. 실제 프린터 출력과 드라이버별 색상/배율은 별도 미검증이다.

## 검증 자료

작업 공간의 `evidence/design-patch/`에 `badge-logo-browser-report.json`, `pdf-design-content-report.json`, PDF 8개, 화면 이미지, 24페이지 `pdf-contact-sheet.png`가 있다. `regression/`에는 기존 기능 검사 보고서와 선택/전체/시험 자 PDF가 있다. 브라우저 검사는 `playwright`와 `pdf-lib`가 필요하며 `BADGE_BROWSER`, `BADGE_EVIDENCE`로 실행 브라우저와 결과 위치를 지정할 수 있다.

## 승인 후 릴리스 확인

승인된 릴리스는 최신 main을 기준으로 명찰 관련 파일만 커밋하고 PR을 통해 병합한다. 기존 Pages 배포 성공, 공개 URL의 HTTP 응답과 배포 파일 해시, 공개 제작기의 브라우저 회귀 검사를 별도 확인한다. 작업 공간의 `evidence/design-release/`에 소스 커밋·PR·병합 커밋·Pages 실행·공개 검증 결과를 기록한다. 소스 검증 결과만으로 운영 배포 성공을 판단하지 않는다.

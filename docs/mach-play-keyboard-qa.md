# MACH 탐험 키보드·발견·점수 패치 검증

2026-10-26. 기준 main: `7cbbc2e18e485be569d2f8e6008fa637e6085010` (명찰 PR30 병합 포함). 로컬 브랜치 `feat/mach-play-keyboard-discovery`. 이 문서는 로컬 검증 결과이며 새 패치의 커밋·푸시·배포 완료를 뜻하지 않습니다.

## 구현

- 공개 건물 파괴 시 건물 위에 실제 도구 설명 패널. 가까운 최근 건물 하나만 표시하고 복구 후 제거합니다. 입구와 복구는 계속 사용합니다.
- 모든 게임 메뉴에 방향키·Enter·Esc와 직접 단축키를 적용했습니다. 엘리베이터 자동 초점과 캔버스 복귀, 입력/IME 보호, 반복 공격/Enter 차단, 기본 Tab 이동을 유지합니다.
- 두 가지 보조 기능은 H 즉시 도움말과 C 세션 발견 도감입니다. 도구 발견과 짧은 휴식을 돕고 계정·저장소·추적 없이 동작합니다.
- 공개 건물당 첫 파괴 150점, 18개 합계 2,700점. 적 100/100/150/200 유지, 아군·비공개 구역·철옹성 0점. 회차별 ID 집합으로 복구 반복 득점을 차단합니다.
- 천점 안내는 비차단 순서 큐이며 10,000점 도달 시 대기 알림을 비우고 엔딩 한 번만 표시합니다. 점수 상한 10,000, 키보드 새 라운드 또는 점수 고정 자유탐험을 제공합니다.
- 1,000점 문구: ‘마하에 있으면 좋을 기능이 떠오르셨나요? 제작자에게 아이디어를 남겨주세요!’ / 5,000점: ‘심심하세요?’ / 10,000점: 축하 + GAME END. F의 기존 공개 의견 양식은 사용자 선택으로만 열립니다.
- 적 이름은 연한 불투명 배경과 빨간 테두리·문자로 표시합니다. 아군 칼퇴 요정은 초록색입니다.
- 하이비비 승인 도트 01·02를 공식 Library helper로 받은 ZIP에서 추출했습니다. PNG 바이트·투명도·6×6 픽셀 블록을 검증하고 실제 그림을 확인했습니다. 768×768 PNG는 그대로이며 렌더 크기만 128→102px(-20.3%)로 조정했습니다. 발 접지·풀숲·이름표를 확인했고 이름 글자 크기 16px와 말풍선은 유지합니다.
- 부모 iframe의 실제 보이는 영역에 맞춰 메뉴 위치·높이를 제한합니다. 320px 도움말은 단일 열로 표시하고 메뉴 안에서 스크롤합니다.

## 검증

`node --test tests/mach-play*.cjs`: **40/40 통과**. `git diff --check` 통과.

- 실제 game.js + physics.js를 실행한 DOM/rAF 회귀 검사: 포커스 범위, 한글 KeyX, IME, 반복 키, 모달 중 공격 취소, 엘리베이터, 메뉴, 복구 재파괴, 천점 안내, 엔딩 1회·최댓값, 자유탐험, 재시작 초기화, 철옹성 반동, blur/visibility 정지, 선택형 의견 링크.
- Chrome 로컬 실제 키보드: 접이식 Enter → 자동 시작 초점 → Enter 시작 → 좌측 이동 → ↑ 엘리베이터 → ↓/Enter 2층 → 이동·X 공격 → H/Esc → M 처음 위치 → X 건물 설명·150점 → 이동/R/X 중복 득점 없음 → V 속도 440→430 → G 캐릭터 → C 검색에서 ‘명찰x’ 입력(게임 공격 없음) → Backspace/Enter 결과 선택 → F 안내 → M/방향키/Enter 접기 → iframe 0개 → Enter 재열기·초기화.
- 390px 건물 패널과 320px 도움말 실제 화면 확인, 가로 넘침 없음. 작은 화면 제목·닫기 겹침과 iframe 높이 기준 메뉴 잘림을 수정하고 재확인했습니다.
- 엔딩 UI는 배포 디렉터리 밖의 별도 로컬 QA 사본에서 시작 점수만 9,850으로 지정했습니다. 실제 X로 건물을 부숴 10,000점 → 방향키/Enter 자유탐험 → 10,000 고정과 공개 링크 18개 → 메뉴 새 라운드 → 0점 → 첫 건물 150점을 확인했습니다. 운영 소스에는 점수 주입 코드가 없습니다.
- 기존 승인 PNG 24개와 공격 애니메이션 모듈의 원본 해시는 유지됩니다. 새 하이비비 두 PNG는 승인 ZIP 원본 해시와 일치합니다.
- 원격 main 읽기 확인: 기준 커밋과 일치. 명찰 16개 파일과 개인 사이트는 변경하지 않았습니다.

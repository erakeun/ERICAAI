## 배포 후 실제 운영 URL 재검증

운영 주소 `https://erakeun.github.io/ERICAAI/interview-oneq/`에서 Codex 내부 브라우저로 첫 화면(프로젝트0개), 새 프로젝트, 위원/회차/가상지원자3명 직접입력, 전체 자동배정3/3, 새로고침 저장 보존, 질문·배점표, 지원자별3쪽 인쇄 미리보기를 확인했다. 운영본의 새 명패 및 안내문 JSON을 실제 다운로드하고 위원 이름·소속·직위·역할과 면접명·건물·호실·날짜·시간을 파일에서도 대조했다.

모바일390×844에서 현장 상태를 직접 변경했다. 페이지 가로넘침0, 상태 선택300×44px, console error/warn0. 운영본이 만든 `?building=101` 링크를 공개 캠퍼스맵으로 열어 본관 강조를 확인했다. 기존 MACH 홈의26개 카드와 면접 도구 연결을 확인했다.

제작기 가져오기 완료 alert로 내부 브라우저 입력이 일시 정체된 현상은 테스트 세션 정리 후 해소됐다. 이후 안내문에 실제20명 프로젝트의 면접명·본관202호·일시·방향·안내문구가 정확히 표시되고 재시작 후 유지됨을 확인했다. 공개 제작기의 기존 사용자 작업은 유지했다.

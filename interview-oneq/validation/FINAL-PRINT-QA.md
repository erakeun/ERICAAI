# 최종 인쇄 QA

검증일: 2026-09-29. 가상 지원자 20명, 면접위원 3명, 이틀의 오전·오후 4개 회차(개인면접 3개, 조별면접 1개)로 검증했다. 실제 지원자 개인정보를 사용하지 않았다.

## 결과

9종 문서를 A4 세로·가로로 생성하고, 긴 평가항목 10개를 적용한 추가 평가표 2종을 포함하여 **20개 PDF / 124쪽**을 검사했다. 모든 페이지를 Poppler로 PNG 렌더하고 각 문서의 첫 페이지·이어지는 페이지·마지막 페이지 및 평가표의 일반/긴 입력 형식을 시각 검토했다. 반복되는 평가표 전체에는 별도로 페이지별 지원자번호와 메타데이터를 검사했다.

- 자동 문서 검사: 빈 페이지 0, 페이지 밖 텍스트 0, 문서버전·출력시각·쪽번호 누락 0.
- 평가표 DOM 높이 초과 0. PDF에서도 각 평가표 페이지에 지원자번호가 정확히 하나씩 존재한다.

- 공개 게시물에 이름·연락처·메모·점수·합격결과가 포함되지 않는다. 내부 연락처·운영메모는 운영자용 패킷으로 제한된다.
- 기존 인쇄 단위 테스트 13개를 유지하고 3개를 추가하여 **16/16 통과, 실패·skip 0**. 독립 출력 9종, 20명 평가표, 반복 푸터의 안전한 문자열 처리를 추가 검증했다.

## 발견 후 수정

1. 출석부 세로에서 푸터만 새 페이지로 넘어가던 문제: 인쇄 푸터를 용지 여백으로 옮겨 불필요한 페이지를 제거했다.
2. 여러 쪽짜리 게시물의 중간 페이지에서 버전·시각을 알 수 없던 문제: 모든 물리적 페이지 하단에 버전·한국시간·개인정보 범위·쪽번호를 반복한다.
3. 운영자 패킷 가로에서 운영메모 칸 하단만 다음 페이지로 분리되던 문제: 칸 분리를 방지하고 가로의 메모 높이를 조정했다.
4. 평가기준표 가로에서 진행방법만 별도 페이지로 넘어가던 문제: 평가기준 열너비와 가로 출력 간격을 조정했다.
5. 시간표·질문지·기준표가 위원 패킷 안에만 있던 문제: 3개를 독립 출력 형식으로 제공한다.
6. 현장 게시물의 호실만으로 건물을 구분할 수 없던 문제: 건물명과 호실을 함께 표시한다.

## 증거와 한계

검증 입력·20개 PDF·렌더 PNG·페이지별 분석 JSON은 프로젝트 작업공간의 `work/final-print-qa/`에 보관했다. 생성 스크립트는 `work/final-print-qa.mjs`, PDF 분석·렌더 스크립트는 `work/final-print-review.py`다. 소스는 `print.js`, `print.css`, 회귀 테스트는 `tests/print.test.mjs`이다.

PDF는 격리된 Chromium 인쇄 엔진으로 생성했다. Codex 내부 브라우저의 앱 UI·출력센터 검수와는 별도 검증이며, 이 보고서가 내부 브라우저 검수를 대체하지 않는다. 실물 프린터 출력, 프린터별 여백·양면 설정, 실제 휴대전화 QR 스캔은 수행하지 않았으며 미검증이다. 임의로 매우 긴 사용자 입력의 모든 가능한 길이를 보장하는 검증은 아니며, 기본 항목 및 긴 10항목 형식을 검사했다.

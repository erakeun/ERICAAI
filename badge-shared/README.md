# MACH 명찰 제작기

목걸이형과 집게·옷핀형의 **삽입지**를 만드는 브라우저 도구입니다. 플라스틱 홀더나 목걸이 끈을 제작하는 도구가 아닙니다.

- [목걸이 명찰 제작기](https://erakeun.github.io/ERICAAI/lanyard-badge/)
- [집게·옷핀 명찰 제작기](https://erakeun.github.io/ERICAAI/clip-badge/)

## 처음 사용하는 순서

1. 홀더에 들어가는 종이의 **가로 × 세로 mm**를 확인합니다. 외곽 치수를 입력하지 마세요. 제조사 확인 규격을 선택하거나 직접 입력합니다. 방향을 바꾸면 가로와 세로가 서로 바뀝니다.
2. 여덟 시안 중 하나를 선택하고 로고를 **없음 / 한양대학교 / ERICA / 둘 다** 중에서 고릅니다. 행사명, 소속, 직책, 이름과 필요한 날짜를 입력하면서 미리보기를 확인합니다. 더 조정하려면 **세부 디자인 조정**을 펼칩니다.
3. 한 명씩 추가하거나 엑셀의 표를 복사해 명단 입력란에 붙여넣습니다. CSV·TSV 파일도 사용할 수 있습니다. 머리글 없는 자료는 이름, 소속, 직책, 행사명, 날짜 순서이며 날짜는 선택적인 다섯 번째 열입니다. 기존 네 열 자료도 그대로 읽습니다. 머리글을 쓰면 `이름,소속,직책,행사명,날짜`처럼 열을 구분할 수 있습니다. 샘플은 모두 가상 자료입니다.
4. A4 용지 여백, 명찰 사이 간격, 명찰 안쪽 여백, 재단선과 글자 크기를 확인합니다. 한 장에 몇 개가 들어가는지와 필요한 장수가 자동 계산됩니다. 넘침 경고가 있으면 이름 크기를 줄이거나 규격과 여백을 조절합니다.
5. 개별 또는 전체 인쇄를 선택합니다. 인쇄 대화상자에서 PDF로 저장할 수도 있습니다. **A4 세로 · 배율 100%/실제 크기 · 브라우저 여백 없음 · 머리글/바닥글 해제 · 배경 그래픽 켜기**를 사용합니다. 앱에서 지정한 A4 여백은 인쇄 내용에 이미 포함됩니다.
6. 먼저 100 mm 눈금과 한 장만 시험 인쇄합니다. 실물 눈금과 홀더 적합성을 확인한 다음 여러 장을 출력합니다. 프린터의 비인쇄 영역, 급지 오차와 드라이버의 자동 축소는 브라우저에서 확정할 수 없습니다.

## 디자인과 로고 선택

두 제작기는 아래 여덟 시안을 함께 제공합니다. 삽입지의 가로·세로와 방향을 바꿔도 선택한 시안과 로고를 유지합니다.

| 시안 | 구성 | 참고한 기존 도구 |
| --- | --- | --- |
| 한양 블루 | 블루 상단과 흰 본문 | 안내문 Classic Blue |
| 공식 심플 | 흰 바탕과 골드 구분선 | 메일 명함 Gold Rule |
| 하냥이 | 하냥이 캐릭터와 밝은 블루 면 | 메일 명함 캐릭터 배치 |
| HiBB | HiBB 캐릭터와 밝은 보랏빛 면 | 메일 명함 캐릭터 배치 |
| 행사·스태프 | 네이비 바탕과 골드 역할 표기 | 디지털 사이니지 딥 네이비·골드 다크 |
| 블루 시그널 | 행사명을 담은 하단 블루 띠 | 메일 명함 Blue Signal |
| 네이비 프레임 | 테두리와 하단 사선 | 행사용 명패 네이비 프레임 |
| 네이비 사이드 | 측면 패널과 골드 선 | 메일 명함 Navy Gold Frame |

로고는 시안과 별도로 고릅니다. **없음**은 대학 로고를 숨기고, **한양대학교**와 **ERICA**는 해당 원본 하나를, **둘 다**는 두 원본을 함께 표시합니다. 새 작업의 기본값은 **둘 다**입니다. 어두운 로고 영역에는 기존 흰색 원본을 사용하고 밝은 영역에는 블루 원본을 사용합니다. 대학 로고의 색·글자·비율은 바꾸지 않습니다. **없음**을 골라도 하냥이·HiBB 시안의 캐릭터는 유지됩니다.

## 세부 디자인 조정

기본 화면에서는 접혀 있는 **세부 디자인 조정**을 펼치거나, **명찰** 미리보기의 글자·로고를 눌러 선택합니다. 목록에서 **이름, 소속·기관, 직책·역할, 행사명, 날짜, 한양대학교 로고, ERICA 로고**의 일곱 요소를 고를 수 있습니다. 이 설정은 현재 시안의 모든 명찰에 적용됩니다. 명단에서 다른 사람을 선택해 긴 문구도 확인하세요.

| 조정 항목 | 사용 방법 |
| --- | --- |
| 위치 X·Y | 삽입지 왼쪽 위가 `0, 0`입니다. 요소 상자의 왼쪽 위 위치를 **mm**로 입력합니다. 명찰 미리보기에서 직접 끌어 옮긴 뒤 숫자로 미세 조정할 수 있습니다. |
| 상자 크기 | 글자는 너비·높이를 **mm**로 지정합니다. 로고는 너비만 바꾸며 원본 비율로 계산한 높이를 보여줍니다. |
| 글자 모양 | 요소마다 글꼴, **pt** 크기, 왼쪽·가운데·오른쪽 정렬, 색상 선택 또는 HEX 값을 지정합니다. `#048` 같은 세 자리 색상도 입력할 수 있습니다. |
| 줄 간격·자간 | 추가 항목을 펼쳐 조정합니다. 줄 간격은 글자 크기의 배수, 자간은 **em** 단위입니다. 자간 `0`은 기본 간격입니다. |
| 표시 여부 | 글자는 **명찰에 표시**를 끄면 내용을 지우지 않고 숨깁니다. 숨긴 요소는 목록에서 다시 선택합니다. 로고 표시 여부는 위의 **명찰에 넣을 로고**에서 바꿉니다. |

**상자에 맞춰 자동 축소**를 켜면 입력한 pt에 **전체 글자 크기** 비율을 적용한 값을 최대 크기로 삼고, 사람마다 내용이 상자에 들어가도록 줄입니다. 현재 미리보기에 적용된 pt와 자동 축소 여부를 표시합니다. 이 체크를 끄면 **수동**이며 입력한 pt를 그대로 유지하고 전체 글자 크기 비율도 적용하지 않습니다. 크기 숫자만 바꿔서는 자동·수동 모드가 바뀌지 않습니다. 수동 문구가 상자를 넘으면 크기나 상자·위치를 직접 조정해야 합니다.

글꼴은 **Pretendard, SUIT, Noto Sans KR, Noto Serif KR, 시스템 기본 글꼴** 중에서 고릅니다. 기기에 설치된 글꼴을 사용하며 외부에서 내려받지 않습니다. 선택한 글꼴이 없으면 대체 고딕·명조체로 표시되므로 실제 인쇄할 기기에서도 줄바꿈과 크기를 확인하세요.

키보드로는 미리보기 요소에 Tab으로 이동한 뒤 Enter 또는 Space로 선택할 수 있습니다. 방향키는 **0.1 mm**, Shift+방향키는 **1 mm**씩 이동합니다. Escape는 현재 이동을 마치고 요소 선택 목록으로 초점을 옮깁니다. 드래그가 중단되어도 마지막으로 보인 위치는 유지됩니다. 숫자를 비우거나 허용 범위를 벗어나면 마지막 적용값을 유지하고, 입력란을 떠날 때 그 값으로 되돌립니다.

조정은 **시안마다 따로 보관**됩니다. 다른 시안으로 바꿨다가 돌아오면 이전 조정이 유지됩니다. 규격·방향을 바꾸어도 직접 입력한 mm 설정은 남으므로, 작은 규격으로 바꾼 뒤에는 영역을 벗어난 요소가 없는지 확인하세요.

- **선택 요소 초기화**: 선택한 요소의 위치·크기·글자 모양·표시 등 세부 조정을 현재 시안 기본값으로 되돌립니다.
- **현재 디자인 초기화**: 현재 시안의 모든 요소 조정만 되돌립니다.

두 초기화 모두 명단, 입력 내용, 로고 선택, 삽입지 mm, 인쇄 설정과 다른 시안의 조정을 유지합니다. 빈 내용은 표시되지 않으며, 이름을 숨겨도 명단의 이름 입력은 필수입니다. 넘침·겹침 경고가 있으면 수정한 뒤 인쇄하세요. 선택 표시와 편집 안내는 출력물에 포함되지 않습니다.

## 행사명과 날짜

**공통 행사명·공통 날짜**는 명단의 해당 개별 값이 비었을 때 사용합니다. **이 사람의 행사명·날짜 따로 설정**을 펼치거나 명단 표의 개별 칸에 입력하면 그 사람에게는 개별 값이 우선합니다. 개별 날짜와 공통 날짜가 모두 비면 날짜를 표시하지 않습니다. 날짜는 입력한 문구 그대로 사용하며 형식이나 시간대를 자동 변환하지 않습니다.

CSV·TSV의 날짜 머리글은 `날짜` 또는 `date`입니다. 내보내는 CSV에는 `이름,소속,직책,행사명,날짜` 다섯 열이 포함됩니다. CSV는 명단의 개별 값만 보관하므로 공통 행사명·날짜와 세부 디자인까지 이어서 사용하려면 JSON 작업 파일을 저장하세요.

## 명단과 작업 파일

명단과 디자인 설정은 브라우저 안에서 처리됩니다. 외부 분석 서비스나 서버에 이름을 보내지 않으며 자동 저장하지 않습니다. 작업을 보관하려면 **작업 저장**으로 JSON 파일을 직접 내려받으세요. 그 파일에는 명단이 포함됩니다. 공유할 때 수신자와 내용을 확인하세요. 불러오기는 현재 편집 상태를 바꾸므로 필요한 상태를 먼저 저장합니다.

현재 작업 파일은 **버전 2 JSON**이며, 명단·공통 행사명·공통 날짜·로고 선택·규격·인쇄 설정과 시안마다 보관한 세부 조정을 함께 저장합니다. 기존 **버전 1**도 불러올 수 있고, 없던 날짜와 세부 조정은 빈 값·기본 배치로 시작합니다. 로고 선택이 없던 예전 작업은 이전과 같은 **한양대학교** 로고로 열립니다. 다시 저장하면 버전 2가 됩니다.

CSV로 내보낼 때 스프레드시트의 수식으로 해석될 수 있는 셀은 앞에 작은따옴표를 붙입니다. 앱 화면과 출력의 원래 이름은 변경하지 않습니다. 가져온 HTML 문법은 실행되지 않고 문자로 표시됩니다.

## 디자인과 검증

기존 메일 명함·안내문·디지털 사이니지·행사용 명패의 실제 소스와 배경 이미지를 확인한 후 구성을 명찰 크기에 맞게 재구성했습니다. 한양대학교·ERICA 로고와 캐릭터는 기존 원본 파일을 그대로 사용합니다. 원본 경로, 커밋, SHA-256, 로고 크기·투명도, 여덟 시안의 대응 자료는 [디자인 근거](design-provenance.md)에 기록합니다.

개별 미리보기, A4 배치, 선택 인쇄와 전체 인쇄는 같은 명찰 렌더링과 세부 디자인 설정을 사용합니다. 앱은 출력할 명찰의 넘침·겹침을 확인하며, 문제가 있으면 수정을 안내합니다. 실제 크기와 프린터 오차는 100 mm 자와 시험 인쇄로 확인하세요. 실물 프린터 출력은 별도 미검증입니다.

**의견 남기기 ↗**는 해당 제작기의 별도 접수 화면을 새 탭으로 엽니다. 목걸이형은 MACH 30번, 집게·옷핀형은 31번으로 연결되며 명단·이름·디자인 설정은 전송하지 않습니다. 2026-10-26 운영 GET 조회로 두 제작기의 정확한 제목을 확인했습니다.

# MACH 명찰 제작기

목걸이형과 집게·옷핀형의 **삽입지**를 만드는 브라우저 도구입니다. 플라스틱 홀더나 목걸이 끈을 제작하는 도구가 아닙니다.

- [목걸이 명찰 제작기](https://erakeun.github.io/ERICAAI/lanyard-badge/)
- [집게·옷핀 명찰 제작기](https://erakeun.github.io/ERICAAI/clip-badge/)

## 처음 사용하는 순서

1. 홀더에 들어가는 종이의 **가로 × 세로 mm**를 확인합니다. 외곽 치수를 입력하지 마세요. 제조사 확인 규격을 선택하거나 직접 입력합니다. 방향을 바꾸면 가로와 세로가 서로 바뀝니다.
2. 여덟 시안 중 하나를 선택하고 로고를 **없음 / 한양대학교 / ERICA / 둘 다** 중에서 고릅니다. 행사명, 소속, 직책, 이름을 입력하면서 미리보기를 확인합니다.
3. 한 명씩 추가하거나 엑셀의 표를 복사해 명단 입력란에 붙여넣습니다. CSV 파일도 사용할 수 있습니다. 머리글 없는 자료는 이름, 소속, 직책, 행사명 순서입니다. 머리글을 쓰면 `이름,소속,직책,행사명`처럼 열을 구분할 수 있습니다. 샘플은 모두 가상 자료입니다.
4. A4 용지 여백, 명찰 사이 간격, 명찰 안쪽 여백, 재단선과 글자 크기를 확인합니다. 한 장에 몇 개가 들어가는지와 필요한 장수가 자동 계산됩니다. 넘침 경고가 있으면 이름 크기를 줄이거나 규격과 여백을 조절합니다.
5. 개별 또는 전체 인쇄를 선택합니다. 인쇄 대화상자에서 PDF로 저장할 수도 있습니다. **A4 세로 · 배율 100%/실제 크기 · 브라우저 여백 없음 · 머리글/바닥글 해제 · 배경 그래픽 켜기**를 사용합니다. 앱에서 지정한 A4 여백은 인쇄 내용에 이미 포함됩니다.
6. 먼저 100 mm 눈금과 한 장만 시험 인쇄합니다. 실물 눈금과 홀더 적합성을 확인한 다음 여러 장을 출력합니다. 프린터의 비인쇄 영역, 급지 오차와 드라이버의 자동 축소는 브라우저에서 확정할 수 없습니다.

## 디자인과 로고 선택

두 제작기는 아래 여덟 시안을 함께 제공합니다. 삽입지의 가로·세로와 방향을 바꿔도 선택한 시안과 로고를 유지합니다.

| 시안 | 구성 | 참고한 기존 도구 |
| --- | --- | --- |
| 한양 블루 | 블루 상단과 흰 본문 | 안내문 Classic Blue |
| 공식 심플 | 흰 바탕과 골드 구분선 | 메일 명함 Gold Rule |
| 하냥이 | 하냥이 캐릭터와 밝은 블루 면 | 메일 명함 캐릭터 배치 |
| HiBB | HiBB 캐릭터와 밝은 보랏빛 면 | 메일 명함 캐릭터 배치 |
| 행사·스태프 | 네이비 바탕과 골드 역할 표기 | 디지털 사이니지 딥 네이비·골드 다크 |
| 블루 시그널 | 행사명을 담은 하단 블루 띠 | 메일 명함 Blue Signal |
| 네이비 프레임 | 테두리와 하단 사선 | 행사용 명패 네이비 프레임 |
| 네이비 사이드 | 측면 패널과 골드 선 | 메일 명함 Navy Gold Frame |

로고는 시안과 별도로 고릅니다. **없음**은 대학 로고를 숨기고, **한양대학교**와 **ERICA**는 해당 원본 하나를, **둘 다**는 두 원본을 함께 표시합니다. 새 작업의 기본값은 **둘 다**입니다. 어두운 로고 영역에는 기존 흰색 원본을 사용하고 밝은 영역에는 블루 원본을 사용합니다. 대학 로고의 색·글자·비율은 바꾸지 않습니다. **없음**을 골라도 하냥이·HiBB 시안의 캐릭터는 유지됩니다.

## 명단과 작업 파일

명단과 디자인 설정은 브라우저 안에서 처리됩니다. 외부 분석 서비스나 서버에 이름을 보내지 않으며 자동 저장하지 않습니다. 작업을 보관하려면 **작업 저장**으로 JSON 파일을 직접 내려받으세요. 그 파일에는 명단이 포함됩니다. 공유할 때 수신자와 내용을 확인하세요. 불러오기는 현재 편집 상태를 바꾸므로 필요한 상태를 먼저 저장합니다.

작업 파일에는 선택한 시안과 로고도 함께 저장됩니다. 로고 선택이 없던 기존 버전 1 작업 파일을 불러오면 이전과 같은 **한양대학교** 로고를 표시합니다.

CSV로 내보낼 때 스프레드시트의 수식으로 해석될 수 있는 셀은 앞에 작은따옴표를 붙입니다. 앱 화면과 출력의 원래 이름은 변경하지 않습니다. 가져온 HTML 문법은 실행되지 않고 문자로 표시됩니다.

## 디자인과 검증

기존 메일 명함·안내문·디지털 사이니지·행사용 명패의 실제 소스와 배경 이미지를 확인한 후 구성을 명찰 크기에 맞게 재구성했습니다. 한양대학교·ERICA 로고와 캐릭터는 기존 원본 파일을 그대로 사용합니다. 원본 경로, 커밋, SHA-256, 로고 크기·투명도, 여덟 시안의 대응 자료는 [디자인 근거](design-provenance.md)에 기록합니다.

브라우저 PDF는 실제 mm, A4 페이지 수, 명단 순서와 재단선 배치를 자동 검사합니다. 화면 검증과 PDF 검증은 실물 프린터 검증을 대신하지 않습니다. 실물 프린터 출력은 별도 미검증입니다.

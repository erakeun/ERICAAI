# 하냥이의 마하탐험 · 공개판

기존 게임의 승인된 달리기·할퀴기 애니메이션과 철옹성 반동을 이어받은 정적 공개 사본입니다. 원본 게임 및 별도 비공개 사이트의 접근 설정을 변경하지 않습니다.

공개 도구의 이름·주소·짧은 설명은 이 저장소의 `index.html` 프로젝트 목록과 `assets/usage-guides.json` 사용 안내를 기준으로 작성했습니다. 목걸이형 명찰(MACH 30)과 집게·옷핀형 명찰(MACH 31)을 포함한 18개 도구를 수록합니다. 도구 포털은 새 탭으로 열립니다.

비공개 건물은 주소나 업무 내용을 담지 않는 게임 속 표식입니다. 철옹성은 출입할 수 없으며 공격으로 파괴되지 않습니다.

게임은 메인 페이지의 접이식 영역을 펼칠 때 불러옵니다. 게임 화면에 포커스가 있을 때만 방향키·스페이스·X로 조작하며, Tab으로 조작 영역을 벗어날 수 있습니다. 접으면 실행 중인 게임을 종료하고 다시 펼칠 때 처음부터 시작합니다.

## 키보드와 발견 기록

Enter로 시작하고 `↑`로 가까운 엘리베이터·포털·하이비비를 이용합니다. 메뉴는 방향키 선택, Enter 확인, Esc 취소이며 Tab도 유지됩니다. `M/Esc` 메뉴, `H` 도움말, `C` 도구 목록, `G` 캐릭터, `V` 속도, `P` 정지·재개, `R` 건물 복구, `F` 의견 안내입니다. 검색 입력과 한글 조합 중에는 게임 단축키가 실행되지 않습니다.

건물을 부수면 해당 도구 설명이 건물 위에 나타납니다. 가까운 설명 하나만 보이며 8초 자동 복구 또는 R 복구 후 사라집니다. 도구 접근과 복구는 계속 가능합니다. 도구에 접근하거나 건물을 부수면 발견 기록에 들어가며 C 메뉴에서 발견한 도구만 모아 볼 수 있습니다. 기록은 열린 게임의 메모리에만 남고 접기·새로고침 시 지워집니다.

## 점수와 엔딩

공개 건물 18개는 회차별 첫 파괴에 각 150점(합계 2,700점)을 줍니다. 복구·재파괴로 중복 득점할 수 없습니다. 기존 적 점수는 100/100/150/200, 아군·비공개 건물·철옹성은 0점입니다. 철옹성은 파괴되지 않고 반동만 줍니다.

매 1,000점의 안내는 플레이를 막지 않습니다. 1,000점은 아이디어 제안 안내, 5,000점은 ‘심심하세요?’, 10,000점은 축하와 GAME END입니다. 최대 표시 점수는 10,000이며 엔딩은 회차당 한 번 열립니다. 새 라운드는 점수·파괴 득점 ID·적·건물·위치를 초기화하고 발견 기록과 사용자 설정은 유지합니다. 자유탐험은 점수를 고정하고 공개 도구를 계속 이용합니다. 의견 양식은 F 안내에서 사용자가 링크를 선택할 때만 열리며 자동 전송하지 않습니다.

하이비비는 승인된 `mascot-approved-pixel-v5`의 01·02 투명 PNG를 수정 없이 사용합니다. 렌더 사각형은 102×102px이며 초기 도트 적용 크기 128×128px보다 20.3% 작습니다. 정수 좌표와 nearest-neighbor 렌더링으로 도트 경계를 유지합니다.

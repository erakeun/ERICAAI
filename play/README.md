# 하냥이의 마하탐험 · 공개판

기존 게임의 승인된 달리기·할퀴기 애니메이션과 철옹성 반동을 이어받은 정적 공개 사본입니다. 원본 게임 및 별도 비공개 사이트의 접근 설정을 변경하지 않습니다.

공개 도구의 이름·주소·짧은 설명은 이 저장소의 `index.html` 프로젝트 목록과 `assets/usage-guides.json` 사용 안내를 기준으로 작성했습니다. 목걸이형 명찰(MACH 30)과 집게·옷핀형 명찰(MACH 31)을 포함한 18개 도구를 수록합니다. 도구 포털은 새 탭으로 열립니다.

비공개 건물은 주소나 업무 내용을 담지 않는 게임 속 표식입니다. 철옹성은 출입할 수 없으며 공격으로 파괴되지 않습니다.

게임은 메인 페이지의 접이식 영역을 펼칠 때 불러옵니다. 게임 화면에 포커스가 있을 때만 방향키·스페이스·X로 조작하며, Tab으로 조작 영역을 벗어날 수 있습니다. 접으면 실행 중인 게임을 종료하고 다시 펼칠 때 처음부터 시작합니다.

# MACH의 속도에 스며든다 NOW

출처: 레인보우 〈MACH〉 가사

아이디어를 AI에게 전달할 구체적인 개발 요청으로 정리하는 정적 도구입니다. 가사 본문이나 음원은 포함하지 않습니다.

`index.html`, `style.css`, `app.js`만으로 실행합니다. 설치·빌드·외부 API·분석 도구가 없습니다. 기본은 탭 메모리, 명시적으로 선택하면 이 브라우저의 localStorage에 저장합니다. 저장 해제/지우기/전체 초기화를 제공합니다. 실제 개인정보·비밀번호·인증키 대신 가상 예시를 사용합니다. CSP의 connect-src는 none이며 답변을 URL에 저장하지 않습니다.

표시명과 부제는 app.js 상단 BRAND에서 변경합니다. 복사가 거절되면 결과를 선택해 ⌘C/Ctrl+C로 복사하도록 안내합니다.

## 검증

```sh
node now/tests/test.cjs
node --check now/app.js
```

Node VM 로직 검사 15항목 통과. DOM 대역을 사용하므로 브라우저 테스트가 아닙니다. 실제 PC/모바일 화면·키보드 접근·복사·네트워크 실측 및 스크린샷은 미검증입니다. 작업 도구가 file URL 접근을 거절하고 동일 결과의 우회 접근을 금지하여 다른 서버/브라우저로 재시도하지 않았습니다. 이 제한을 검증 통과로 해석하지 않습니다.

기존 ERICAAI 홈에는 검색/필터 바로 아래와 페이지 맨 아래에 독립 전체 클릭 배너 두 개만 추가합니다. main 루트의 기존 GitHub Pages 자동 빌드 설정을 변경하지 않습니다. 원상 복구는 이 추가 커밋을 revert하는 방식으로 진행할 수 있습니다.

디자인 취향 단계는 범주별 태그 토글과 개수 제한, 밝기 상호배타, AI 추천/모르겠음 선택을 제공합니다. 자체 CSS 예시만 보여주며 참고 URL을 방문하거나 이미지를 수집하지 않습니다. 선택한 선호만 구체적인 지시로 변환하고, 미정인 항목은 AI와 확인할 사항에 남깁니다. 자유 입력 사이 모순은 임의 해결하지 않습니다.

상단 사용방법은 네이티브 details/summary와 5개 텍스트 단계입니다. 자동제작/AI 자동연결 없이 직접 요청문을 사용하는 흐름을 안내하며 별도 클릭 핸들러나 history 변경은 없습니다.

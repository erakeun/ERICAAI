아래는 이 사이트의 같은 빈칸 양식과 진행 안내입니다. 복사한 뒤 직접 AI에 붙여넣으면 AI가 쉬운 질문으로 함께 채우도록 요청합니다. 자동 연결·전송은 없고 현재 작성한 답변은 포함하거나 지우지 않습니다.

붙여넣은 뒤 AI의 질문에 답하고, 최종 요청문을 확인하세요. 직접 작성으로 돌아와도 이 화면의 기존 답변은 유지됩니다.

사용방법 · 처음이라면 5단계로 살펴보세요

AI에게 전달할 개발 요청문을 만드는 도구입니다. 사이트를 자동 생성하지 않으며 AI에 자동 연결하거나 입력을 전송하지 않습니다.

  1. 상황을 자세히 적기현재 하는 일과 순서를 적어요. 모르면 ‘모르겠어요’를 누르고 가상 예시와 꿀팁을 활용하세요.
  2. 디자인과 제약 고르기디자인 태그와 기기·저장·비용·주의사항을 정해요. 미정인 내용은 AI와 확인할 사항으로 남아요.
  3. 최종 요청문 검토·수정검토 단계에서 요청문을 직접 수정하세요. 질문 답을 바꾸면 다시 조합되므로 직접 고친 결과는 먼저 복사하세요.
  4. 사용하는 AI에 직접 붙여넣기요청문을 복사해 사용하는 AI 대화창에 붙여넣으세요. 자동 복사가 실패하면 결과를 선택해 Mac은 ⌘C, PC는 Ctrl+C로 복사하세요.
  5. 작은 버전부터 제작·검증AI 질문에 답하고 방향을 합의한 뒤 핵심 흐름부터 만드세요. 가상 자료로 실행해 기대결과를 확인하세요.

기본 입력은 탭 메모리에만 있어 새로고침·종료하면 사라져요. ‘이 기기에 입력 보관’을 선택한 경우에만 저장해요. 공용 PC에서는 선택하지 마세요. 저장본 지우기와 전체 초기화를 사용할 수 있어요.

전체 초기화는 모든 입력을 지우고 예시 불러오기는 첫 개발 탭의 답을 덮어써요. 확인 창을 읽고 진행하세요. 실제 개인정보·비밀번호·인증키는 넣지 마세요.

AI 이용 환경 안내

무료 AI로도 간단한 도구 제작을 시작할 수 있지만, 반복 수정·긴 작업은 사용량 제한으로 중단될 수 있습니다. 유료 AI도 제한이 있으며 완성·품질을 보장하지 않습니다.

AI 구독료에 별도 API 사용료나 호스팅 비용이 포함된다고 가정하지 마세요. 지원 기능과 제한은 현재 이용 환경에서 확인해주세요.
